# Hydrogen Music (v0.2.1-dev 预览开发版)

> **⚠️ 预览开发版本说明**：  
> 本版本为 **Hydrogen Music v0.2.1-dev 预览开发分支**。本分支聚焦于**独立桌面歌词悬浮窗、中西文字体分离渲染引擎、系统级全屏置顶与鼠标穿透锁定**等核心特性的实验与预览，代码已独立模块化归档于 `src/desktopLyric/` 目录，便于与主线开发隔离与独立测试。

## MV 文字动态视频制作

“自制 MV”入口位于播放器“添加视频”弹窗底部空白区域，保持歌词与视频图标排布不变。顶部导航也可直接进入 MV 模块；从弹窗进入会带入当前歌曲信息及已载入的歌词（无原始 LRC 时复用播放器解析后的歌词时间），不会改写播放器歌词。入口沿用“添加视频”弹窗现有关闭行为，并保持当前歌曲与播放状态。制作器导出音频需手动载入本地文件，不会捕获或导出网易云播放流。上游 MIT 许可与第三方声明见 `public/mv/LICENSE`、`public/mv/THIRD_PARTY_NOTICES.md`。

### 1. 独立置顶透明桌面歌词悬浮窗 (`Desktop Lyrics`)
- **独立原生窗口**：在 Electron 主进程中创建独立的轻量级透明窗口（`transparent: true, frame: false`），支持随系统自启动、位置记忆（`bounds` 持久化）与跨显示器自动居中适配。
- **系统最高层级置顶**：采用 `screen-saver` 级别置顶，支持在 Windows 全屏应用/游戏以及 macOS 多工作区全屏模式下保持顶层悬浮展示。

### 2. 中西文字体分离与级联排版渲染
- **双字体独立控制**：突破传统单一字体限制，通过 CSS 变量与 Font Fallback 级联引擎实现中西文字体彻底解耦：
  - **西文字体**：优先渲染英文、数字与特殊符号（如 `Gilroy-ExtraBold`、`Bender-Bold`、`Arial` 等）。
  - **中文字体**：汉字字符自动回退命中第二顺位的中文字体（如 `SourceHanSansCN-Bold`、`微软雅黑` 等）。
- **抗复杂壁纸干扰**：采用 `-webkit-text-stroke` 文字轮廓描边结合双层动态柔和投影（`text-shadow`），搭配独立的主歌词/副歌词字号滑块与透明度通道（`0.1 ~ 1.0`），在任意壁纸背景下均清晰醒目。

### 3. 系统级置顶锁定与 100% 鼠标事件穿透
- **全穿透锁定模式**：在锁定状态下调用 `setIgnoreMouseEvents(true, { forward: true })`，鼠标点击与滚轮完全穿透歌词浮窗，直接操作底层的应用程序或桌面壁纸，不干扰正常办公与游戏。
- **动态悬浮解锁手柄**：锁定状态下浮窗右上角保留微型感应锚点，鼠标悬停时自动短暂解除穿透呈现解锁图标，支持免快捷键直观点击解锁。
- **快捷键与系统托盘联动**：支持全局热键 `Ctrl+Alt+L`（macOS 为 `Cmd+Alt+L`）一键切换锁定；系统托盘右键菜单实时双向同步锁定状态。

### 4. 播放内核毫秒级广播与全状态同步
- **双向数据流**：主播放器与桌面歌词浮窗建立高频广播机制，毫秒级提取原歌词、双语翻译、罗马音注音及纯音乐提示。
- **浮窗反向控制**：悬浮工具栏内置播放/暂停、上一首、下一首、字号快捷缩放 (`A+`/`A-`) 与设置跳转。
- **进程间通信安全克隆保护**：内置 `safeClone` 预处理机制，杜绝 Vue 3 响应式代理（Proxy）在 Electron IPC 结构化克隆时引发的序列化异常与白屏问题。

### 5. 架构模块化隔离 (`src/desktopLyric/`)
- 将桌面歌词原生管理器（`desktopLyricManager.js`）与界面组件（`DesktopLyric.vue`）集中于 `src/desktopLyric/` 目录，与主线标准组件视图分离解耦，保持主干代码轻量纯净。

## 网络与代理

程序**默认直连**：启动时先把 Chromium 会话设为 `direct`，并清空 `HTTP_PROXY / HTTPS_PROXY / ALL_PROXY` 等环境代理，因此系统代理、代理软件的系统级接管不再劫持播放、封面、下载与接口请求（此前本地代理会让歌曲一直加载失败并自动切歌）。

需要走代理时，只在「设置 → 其他 → 网络代理」填写一条地址（如 `http://127.0.0.1:7890`、`socks5://127.0.0.1:1080`，可带 `user:pass@`），**保存后立即生效**：

| 链路 | 代理来源 |
|---|---|
| 音频流 / 封面 / 页面请求 / 下载（Chromium 会话） | 会话代理规则（`proxyRules` + `<local>` 例外），带账号密码时通过 `login` 事件注入 |
| 接口 / 解灰 / 在线曲抓取 / 更新检查（axios） | `http_proxy`/`https_proxy` 环境变量（应用内写入，覆盖 NCM API 服务内部请求） |
| 更新下载、镜像测速、封面直读（Node 核心 http） | 全局 `http(s)` 代理 agent |
| 内置 NCM API（`localhost:36530`）与其它本机地址 | 始终直连，不走代理 |

`socks5` 代理作用于 Chromium 与 axios（需要 `socks-proxy-agent`），Node 核心 http 路径无法使用 socks，会自动回退直连并在主进程日志中提示。

## 网易云风控（-460）处理

`/check/music` 返回 `400 / code -460（检测到您的网络环境存在风险）` 时不再直接判死并切歌：程序会提示风控信息、改用解灰音源兜底，全部失败才跳过，并在提示里给出「设置 → 其他 → 网络代理」的指引。

另外，第三方客户端向网易云上报播放记录（打卡）容易被判定账号异常，设置里新增「同步播放记录（打卡）」开关（默认开启，可随时关闭以降低风控概率）；`@neteasecloudmusicapienhanced/api` 已更新到 4.41.x（含 NMTID / neapi / xeapi 等风控相关修复）。

Web / NAS 部署遵循同一条规则：网关启动与保存设置时都会按「网络代理」重设自身的代理环境（留空 = 直连，忽略网关机器上的系统/环境变量代理；填写 = 网关的 NCM API、B 站、下载等请求只走该代理）。浏览器到网关之间的流量由浏览器自身的代理设置决定，页面无法代管。

### 风控（-460「网络环境存在风险」）

网易云会把调用方 IP 当作 `X-Real-IP` 传给上游：桌面端是 `127.0.0.1`、Web 网关下是浏览器所在内网 IP，这类私有地址容易被判定为异常网络。程序在启动 API 服务前会打开上游的 `ENABLE_RANDOM_CN_IP`（随机中国大陆 IP）并初始化 `global.cnIp`，让上游请求带上大陆 IP；把该环境变量显式设为 `false` 可关闭这一缓解。命中风控时播放器仍会提示并尝试备用音源（`-460` / `-462`）。

真正容易触发风控的仍是「请求从代理出口出去」（代理节点在境外或被标记），因此「默认直连、只在设置里指定代理」是主要规避手段。

## ⚠️ 使用与开发注意事项 (Important Notes)

1. **运行平台与运行环境**：
   - 桌面歌词功能依赖 Electron 原生能力，**仅在桌面客户端模式生效**。在 Web / NAS 浏览器模式下，受浏览器沙盒限制，设置中心会自动隔离隐藏该功能。
2. **本地预览与开发启动流程**：
   - 必须先启动前端热更新服务：`npm run dev`（监听 `http://localhost:5173`）。
   - 随后在另一终端启动 Electron 客户端外壳：`npm start`。
3. **锁定状态交互说明**：
   - 当点击锁定图标或按下 `Ctrl+Alt+L` 锁定后，点击歌词文本不会触发任何响应（事件已完全穿透至底层）。
   - 如需恢复拖拽或操作，可通过以下三种方式之一解锁：
     - **方式一**：鼠标悬停在歌词右上角微型解锁按钮上点击。
     - **方式二**：按下全局快捷键 `Ctrl+Alt+L`（macOS 为 `Cmd+Alt+L`）。
     - **方式三**：右键系统托盘图标，取消勾选「锁定桌面歌词」。
4. **字体配置说明**：
   - 字体输入框支持输入当前操作系统已安装的中英文字体全名，或者项目内置字体名称。
   - 若用户输入的字体名称在系统或项目中不存在，渲染引擎将自动优雅回退到系统默认无衬线字体，不会导致排版错乱或崩溃。
5. **沙盒与分支管理**：
   - 当前版本位于 `dev` 预览开发分支，请勿将未经验收的代码直接合并至 `main` 主线分支。
